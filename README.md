# kushagreekbasu.github.io

Personal portfolio of Kushagreek Basu: research projects and Moksha Motorsports.

- `index.html`, `css/style.css`: page and theme (one font family, fire-and-ice palette).
- `js/fluid.js`: the background, a real-time GPU Navier–Stokes solver (WebGL2, stable fluids with vorticity confinement) that the cursor stirs.
- `js/visuals.js`: live canvas scenes used as project previews (airfoil flow from a Joukowski map, deep-stall wake, scramjet inlet shocks, interactive double-wishbone suspension).
- `js/main.js`: project content, hover previews, project panels, deep links (`#p/dns`, `#p/scramjet`, `#p/fno`, `#p/pinn`, `#p/moksha`).
- `assets/`: renders from my PeleC hydrogen-flame DNS, Moksha photos and FEA images.

No build step. Edit the `PROJECTS` list in `js/main.js` to change text, numbers or media, then push.
